TV Hub - Privacy policy

Last updated: 21 November 2026.

What the app does

TV Hub is a private home-screen app for the owner's Android TV. With the owner's permission it reads documents from one Google Drive folder so they can be shown on the television.

Data accessed

The app requests the Google Drive read-only permission (drive.readonly). It uses it only to list and download the files in the single folder the owner chose, and nothing else in the account.

How data is used and stored

Downloaded files, and the sign-in token that allows the app to keep syncing, are stored only on the owner's own devices (the television and the owner's computer). They are not uploaded to any server run by the developer.

Sharing

The data is not sold, shared, transferred to anyone, or used for advertising, analytics or training of AI or machine-learning models.

Google API Services User Data Policy

TV Hub's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The owner can remove the app's access at any time at myaccount.google.com/permissions, and can delete the stored copies by clearing the app's data on the television.

Contact

Questions can be sent through the issue tracker of this page's GitHub repository.
